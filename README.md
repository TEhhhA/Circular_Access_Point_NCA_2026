This is the supplementary material of the paper "A Circular Low-Power Wi-Fi Access Point based on a Repurposed Smartphone" by Antoine, T., Dethienne, R., & Bol, D. accepted at NCA 2026.

This repo uses submodules. Please use
```
  git submodule update --init --recursive
```
to pull them.

`power_measurement` contains the script used to measure the power consumption of the devices, the data we measured using said scripts and the code which produces the graph which can be found in the paper.

`quality_of_service` contains similar data for the quality of service measurements.

`software` contains the instructions to reproduce the software setup of the Circular Access Point (CAP) described in the paper.

Each folder contains a README with further instructions.
